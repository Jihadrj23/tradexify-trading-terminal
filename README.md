# TradeXify Trading Terminal

Create a modern, professional, and ultra-sleek Web Application for a Gold (XAU/USD) and Crypto Forex Trading Signal & Analysis platform named "TradeXify" (Domain: tradexify.online).



The UI must be designed like a professional trading mobile application (similar to MetaTrader mobile interface style as shown in premium fintech apps) optimized for both mobile and desktop views, featuring a rich dark-textured theme.



1. Branding & Color Palette:

- Brand Name: TradeXify

- Logo: A premium, minimalist dark-themed icon featuring styled letters "TX" with subtle blue and gold highlights.

- Background Color: Deep obsidian black/charcoal (`#0B0E14` or `#121212`) with smooth, premium card containers (dark gray rounded cards with subtle borders).

- Text & Accents: Crisp clean White text for primary details, paired with elegant Blue and Gold accents to give it a high-end trading terminal look.



2. Bottom Navigation Bar (Mobile App Style):

- Fixed bottom navigation bar with icons and text labels for easy switching, matching professional trading apps:

  - Quotes / Home (Overview of XAU/USD live price)

  - Charts (Interactive TradingView live chart widget)

  - Signals / Trade (Active bot multi-strategy consensus signals)

  - History (Past signal performance log)

  - Messages / Alerts (Notifications & bot updates)



3. Main Dashboard & Features:

- Hero / Live Quotes Section: Real-time price tracker for Gold (XAU/USD) with high/low indicators.

- Live TradingView Chart Widget: Embedded full-width interactive chart for technical analysis.

- Signal Status Card: Clean card showing current AI Multi-Strategy consensus (e.g., BUY/SELL, Entry Price, Stop Loss, Take Profit, and Confidence Level based on our 8-rule multi-trader confluence system).



4. Footer & Mandatory Legal Pages (Accessible via clean modals or separate pages):

- Footer with copyright (tradexify.online), mandatory Forex Risk Disclaimer ("Trading carries high risk..."), and links to:

  - Privacy Policy (GDPR & data compliance)

  - Terms and Conditions

  - About Us

  - Contact Us (with a working form layout)



5. Technical Requirements:

- Fully responsive, mobile-first design that looks and feels like a native trading app.

- Clean code structure with mock data placeholders ready for Python backend API integration.
